System Access Architecture Overview

The Real Ested application enforces strict Role-Based Access Control (RBAC) and Multi-Branch Data Isolation across regional hubs (e.g., Pune, Mumbai, Bangalore). Every account type has defined system privileges, data isolation scopes, and operational responsibilities.

Global Scope

Super Admin & Assistant Admin access all branches nationwide with unrestricted read/write permissions.

Branch Isolated Scope

Branch Admins & Sales Executives operate strictly within their assigned regional branch office records.

Assigned Partner Scope

External Brokers only access approved properties in explicitly assigned branch offices.

Detailed Role-by-Role Operating Manual

1. Super Admin Account (super_admin)

Global System Owner & Final Authority
Account Purpose & Scope:

The Super Admin possesses complete system-wide read and write authority. This account is used for high-level administration, audit approvals, branch setup, staff onboarding, property listing overrides, and global lead tracking.

What Needs To Be Done In This Account (Workflows):
A. How to Add, Edit, or Delete Any Property Listing
  1. Add Property: Click Add Property from the sidebar or search catalog. Select the TARGET BRANCH ASSIGNMENT dropdown to assign the property to any regional branch office (e.g., Pune Main Branch).
  2. Edit Property: Open any property details page or search card and click Edit Property Listing. You can modify all parameters, configurations, pricing, and uploaded brochure/image files.
  3. Delete Property: On any property card or detail action bar, click the red Delete button. Confirm the prompt to soft-delete the listing from the catalog.
B. How to Audit & Approve Property Listing Drafts
  1. Navigate to Approvals Queue from the sidebar navigation menu.
  2. Review pending listing drafts submitted by Branch Administrators.
  3. Click Approve to publish the property to the live public site, or click Reject to send it back to the branch for revisions.
C. How to Create and Manage Regional Branch Offices
  1. Navigate to Branches from the sidebar.
  2. Click Create New Branch to register a new location (e.g. Mumbai Suburbs Branch, Code: MUM).
  3. Edit branch information, street address, or contact details anytime.
D. How to Onboard Staff & Assign External Brokers
  1. Staff Directory: Go to Staff Directory → Click Add New User. Assign username, email, password, role, and branch office.
  2. Brokers Control: Go to Brokers Control → Register new channel partners and assign them to specific regional branch office catalogs.

2. Assistant Admin Account (assistant_admin)

Headquarters Operations Manager
Account Purpose & Scope:

Assists the Super Admin in day-to-day central operations. Has global read/write access to create, edit, and delete properties across all branches, manage staff records, and monitor lead activity.

What Needs To Be Done In This Account (Workflows):
Operational Tasks:
  • Create and update property specs across any regional branch.
  • Delete duplicate or obsolete property listings.
  • Monitor lead referral progress across all sales teams.
  • Register sales staff and channel brokers.

3. Branch Admin Account (branch_admin)

Regional Branch Office Head
Account Purpose & Scope:

Restricted to their specific regional branch office scope. Responsible for creating property drafts, maintaining branch inventories, managing local sales executives, and handling local buyer leads.

What Needs To Be Done In This Account (Workflows):
A. Creating & Submitting Property Drafts
  1. Click Add Property → Fill out property specifications, BHK layout pricing, technical specs, amenities, photos, blueprints, and brochures.
  2. Click Save Draft to keep as working draft, or Save & Submit for Review to send it to the Super Admin queue.
B. Managing Branch Staff & Local Lead Referral Routing
  1. Go to Staff Directory to add or update local Sales Executives for your branch.
  2. Go to Lead Referral Tracker to view incoming buyer inquiries and assign them to your branch Sales Executives.

4. Branch Executive / Sales Agent (branch_executive)

Frontline Branch Sales Representative
Account Purpose & Scope:

Frontline sales role operating strictly within their branch office scope. Uses the system to present approved properties to prospective buyers, download marketing collateral, refer leads, and update lead pipeline statuses.

What Needs To Be Done In This Account (Workflows):
Daily Operations & Lead Management
  1. Search Properties: Explore approved listings in your branch catalog to present pricing, carpet area, and EMI calculators to buyers.
  2. Refer Client Lead: Click Refer Client Lead on any property detail page to register a prospective buyer into the pipeline.
  3. Update Lead Pipeline: Navigate to Lead Referral Tracker to update inquiry statuses (New → Contacted → Site Visit Scheduled → Deal Closed).

5. External Broker / Channel Partner (external_broker)

External Channel Partner
Account Purpose & Scope:

External real estate agents assigned to one or more branch office catalogs. Can view approved properties, share custom marketing links with buyer clients, and refer leads for commission tracking.

What Needs To Be Done In This Account (Workflows):
Sharing & Referral Tracking
  1. WhatsApp / Email Share: Open any property detail page → Click WhatsApp Share or Email Share → Enter client contact info to generate a personalized link (automatically logged in broker activity logs).
  2. Refer Lead: Submit buyer referrals to earn channel partner commissions upon deal closing.

Google Maps Embed Integration Guide

When adding or editing a property listing, you can paste the location map embed code into the GOOGLE MAPS EMBED IFRAME URL OR EMBED CODE field.

How to copy Google Maps embed code:
  1. Go to Google Maps and search for your project location.
  2. Click Share → Select the Embed a map tab.
  3. Click COPY HTML.
  4. Paste the copied HTML directly into the property form field:
    <iframe src="https://www.google.com/maps/embed?pb=!1m18!..." width="600" height="450" ...></iframe>

The system automatically sanitizes the input, extracts the clean https://... embed URL, and renders a smooth 16:9 interactive location map on the property listing details page.
